A web application that generates images using artificial intelligence (AI) based on user prompts.

Description
This project was completed as part of a coding practice session to explore the integration of AI tools with web development. The application allows users to enter a prompt, and it generates an image using an AI image generation API.

Features
User-friendly interface for entering image prompts
AI-generated images displayed on the page
Ability to download or save generated images

Technologies Used
React (for the front-end)
Node.js and Express (for the back-end)
OpenAI
CSS (for styling)

Usage
Enter a prompt describing the desired image.
Click the generate button to create an image using AI.
View and download the generated image.
